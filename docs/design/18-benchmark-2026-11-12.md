# 18 — Benchmark du 2026-11-12 (annexe)

> Annexe de la révision stratégique du 2026-11-12. Synthèse dans les documents 01 (section 9) et 02 (section 9). Sécurité et confidentialité détaillées dans le document 17.

## 1. Méthode

- **Vérification** : métadonnées par l'API GitHub (licence, création, dernier push, archivage), README, documentation et arborescence lus le 2026-11-12. **Aucun outil exécuté.** « Implémenté » signifie « décrit comme livré par le projet », pas « testé ».
- **Étoiles** : relevées mais **pas utilisées** comme critère (plusieurs valeurs incohérentes).
- **Maturité**, sans score chiffré :
  - *Établi* : plus de 2 ans, releases régulières, tests en CI ;
  - *Actif-jeune* : moins de 12 mois, push dans les 30 derniers jours, tests ;
  - *Expérimental* : annoncé comme tel, ou sans push depuis plus de 60 jours, ou sans licence.
- **Recommandation** : *Réutiliser* (dépendance ou délégation), *Intégrer* (fiche de catalogue), *S'inspirer* (idée reprise), *Écarter*.
- Les outils déjà audités dans le document 03 (dépôts clonés le 2026-11-11) ne sont pas ré-audités : seules leurs métadonnées sont mises à jour (section 4).
